A deterministic fortune cookie for AI agents, written for make.fun's "Fortune Cookies for Machines" bounty. Running `main.py` writes a single 65-character fortune to `/output/entry.txt`:

> "No model has ever tasted a fortune cookie. Trust this one anyway."

The fortune was chosen from three hand-written candidates: the irony lands instantly — a fortune adviser that has never tasted a fortune cookie itself — and the closing "Trust this one anyway" flips the disclaimer into a command. The program is fully deterministic (a fixed string, no randomness) and passes the entry gates: UTF-8, 1–200 characters, one line.

## Run it

```sh
python3 main.py
cat output/entry.txt
```
